# Novelty Stabilization Gate

## Core Rule

Novelty is not authority.

New patterns may be observed, simulated, and scored, but they may not gain routing, memory, workflow, or civic authority until stabilized, classified, and approved.

## Classifications

```yaml
classification:
  - benign_novelty
  - useful_adaptation
  - suspicious_anomaly
  - sensor_spoofing
  - workflow_corruption
  - authority_escalation
  - runaway_agent_pattern
  - ecological_warning
  - unknown_preserved
```

## Responses

```yaml
responses:
  - observe_only
  - sandbox
  - ask_human_review
  - allow_low_risk_use
  - quarantine
  - revoke_tool_access
  - block_memory_write
  - rollback
  - escalate_to_security
```

## Gate Inputs

```yaml
inputs:
  - anomaly_score
  - source_trust
  - authority_requested
  - tool_scope
  - memory_write_requested
  - public_impact
  - jurisdiction
  - reversibility
  - blast_radius
  - baseline_recoverability
  - simulation_result
```

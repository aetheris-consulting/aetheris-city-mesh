# Aetheris → City Mesh Port Map

| Aetheris Component | City Mesh Role |
|---|---|
| Stewardship Seed | Smallest governed workflow unit inside city operations |
| D2L | Converts raw city telemetry from Dark/Grey into usable Light/Bright evidence |
| Nexus | Maps causal relationships across city systems |
| NeuroMedic | Diagnoses city/system pathologies and manages recovery |
| AHA | Harnesses city agents: robots, drones, AI analysts, human teams |
| AHA-SIM | Runs city-twin simulations before action |
| WEOF | Governs city workflows from observation to action |
| Gate 8 | Prevents unauthorized changes to civic reality |
| LuxFera | Ecological/living-system sensing layer |
| Novelty Stabilization Gate | Handles anomalies, emergent patterns, and mesh behaviors |
| THOS / Telemetry Handshake | Standardizes data exchange between mesh tiers |
| WFKB / WFKC | Stores validated city workflows and cross-city best practices |

## Canonical Loop

```text
Observe city state
→ classify evidence quality
→ map causal topology
→ diagnose pathology or anomaly
→ simulate intervention
→ route through workflow governance
→ commit only with valid authority
→ audit outcome
→ update workflow knowledge commons
```

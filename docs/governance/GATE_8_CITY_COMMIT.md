# Gate 8 City Commit Rule

## Core Rule

Candidate city state is not committed city state.

City Mesh may sense broadly and simulate deeply, but it may only act through governed authority.

## Coupling Classes

```yaml
C0:
  meaning: observation only
C1:
  meaning: advisory recommendation
C2:
  meaning: reversible operational adjustment
C3:
  meaning: consequential civic action
C4:
  meaning: critical life/safety action
```

## Commit Requirements

```yaml
commit_required_fields:
  - validated_evidence
  - jurisdiction
  - legal_authority
  - risk_class
  - simulation_result
  - rollback_plan
  - audit_event
  - approver_or_emergency_protocol
```

## Hard Rules

- Proposal is not action.
- Simulation is not truth.
- Novelty is not authority.
- Optimization is not success unless constraints survive.
